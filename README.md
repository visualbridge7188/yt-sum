 # 🎬 yt-sum — YouTube 자막 추출 및 고밀도 AI 요약기
 
 > **로그인 강제 없음 · 복사 제한 없음 · 유료 결제 유도 없음**  
 > Glasp를 완전히 대체하여 YouTube 영상과 쇼츠에서 자막을 무제한 복사·다운로드하고, 맞춤형 프롬프트와 함께 Gemini · ChatGPT · Claude에 원클릭으로 요약시키는 순수 Chrome / Ego Lite 확장 프로그램(Manifest V3)입니다.
 
 ---
 
 ## ✨ 왜 yt-sum인가요?
 
 기존 도구(Glasp 등)를 사용하면서 겪었던 불편함을 근본적으로 해결했습니다:
 
 * 🚫 **로그인 강제 없음**: 매번 소셜 로그인을 요구하거나 가입을 강제하지 않습니다.
 * 🚫 **자막 복사 횟수 제한 없음**: 하루 복사 횟수 제한이나 유료 Pro 업그레이드 유도가 전혀 없습니다.
 * 🚫 **화면 간섭 제로**: 설명란이나 댓글 창을 저절로 열어 시청을 방해하던 버그를 원천 차단했습니다.
 * 💡 **자유로운 드래그 이동 (FAB)**: 화면 구석을 가리던 버튼 대신, 화면 어디든 원하는 곳으로 드래그해 옮길 수 있는 둥근 자막 아이콘 버튼(FAB)을 제공합니다.
 * 🎯 **실전형 VOD 파이프라인 프롬프트 기본 탑재**: 피상적인 3줄 요약이 아닌, 강사의 실제 발언 워딩(Verbatim)과 비교표를 온전히 살려내는 고밀도 노션 교안 프롬프트가 기본 내장되어 있습니다.
 
 ---
 
 ## 🚀 주요 기능 (Key Features)
 
 ### 1. 4단계 하이브리드 자막 추출 파이프라인
 * **초고속 백그라운드 추출**: 페이지 DOM을 건드리지 않고 백그라운드 네트워크에서 자막 데이터를 신속하게 읽어옵니다.
 * **다국어 자막 완벽 지원**: 한국어(자동 생성/정식 자막)를 최우선으로 감지하며, 영어 등 다국어 자막 목록을 알약 드롭다운으로 손쉽게 전환할 수 있습니다.
 * **쇼츠(Shorts) 1클릭 전환 CTA**: 쇼츠 웹 화면의 자막 차단 시, 파란색 원터치 버튼(`🎬 일반 동영상으로 전환해서 자막·요약 보기 ↗`)으로 일반 플레이어로 즉시 이동하여 1초 만에 전체 자막을 로딩합니다.
 
 ### 2. 가독성을 극대화한 단락형 청킹 (Paragraph Chunking)
 * 1~2초 단위로 파편화된 자막을 30~50초 및 3~4문장의 의미 단위로 깔끔하게 묶어 책처럼 편안하게 읽을 수 있습니다.
 * 각 문단 좌측의 **굵은 블루 타임스탬프(`0:00`, `0:54`)**를 클릭하면 영상의 해당 시점으로 즉시 이동합니다.
 
 ### 3. 드래그 가능한 둥근 플로팅 런처 (Draggable FAB)
 * **모던 다크 글래스모피즘**: 50px 원형 버튼에 선명한 자막 아이콘과 유튜브 레드 닷을 배치했습니다.
 * **자유로운 위치 이동**: 우측 하단, 좌측 하단 등 마우스로 끌어서 원하는 위치에 놓으면 브라우저(`localStorage`)에 좌표가 자동 저장됩니다.
 * **원클릭 숨기기**: 버튼에 마우스를 올렸을 때 나타나는 `✕` 버튼을 누르면 영상 시청을 방해하지 않도록 즉시 숨길 수 있습니다.
 
 ### 4. 노션(Notion) 복사·붙여넣기 최적화
 * 전체 복사 또는 TXT 다운로드 시 **영상 제목 + URL + (MM:SS) 타임스탬프**가 정돈된 순수 마크다운으로 클립보드에 복사됩니다.
 * 노션 빈 페이지에 `Cmd + V`로 붙여넣으면 별도 서식 정리 없이 완벽하게 정돈된 학습 노트가 완성됩니다.
 
 ### 5. 웹 AI 원클릭 자동 연동 (Gemini · ChatGPT · Claude)
 * `[ Gemini ↗ ]`, `[ ChatGPT ↗ ]`, `[ Claude ↗ ]` 버튼을 누르면 선택한 프롬프트와 자막 전체가 클립보드에 안전하게 복사된 뒤 해당 AI 사이트의 새 탭 입력창에 자동으로 주입됩니다.

 ## 🛠️ 설치 방법 (Installation)
 
 ### Google Chrome
 1. Chrome 주소창에 `chrome://extensions/`를 입력하고 접속합니다.
 2. 우측 상단의 **개발자 모드(Developer mode)** 스위치를 켭니다.
 3. 좌측 상단의 **압축해제된 확장 프로그램을 로드합니다(Load unpacked)** 버튼을 클릭합니다.
 4. 본 프로젝트 폴더(`/Users/parkjuncheol/Applications/yt-sum`)를 선택합니다.
 
 ### Ego Lite
 1. Ego Lite 브라우저에서 `chrome://extensions/`로 이동합니다.
 2. **개발자 모드**를 활성화합니다.
 3. **압축해제된 확장 프로그램 로드**를 눌러 동일하게 본 폴더를 선택합니다.

 ## 📂 프로젝트 구조 (Architecture)
 
 ```text
 yt-sum/
 ├── manifest.json        # Chrome Manifest V3 설정 (권한, 호스트, 스크립트 매핑)
 ├── content.js           # 5단 UI 렌더링, 드래그 FAB, 단락형 청킹, 클립보드 복사
 ├── transcript.js        # 4단계 자막 추출 엔진 (DOM + Silent Fetch + TimedText XML + InnerTube)
 ├── styles.css           # 모던 다크 글래스모피즘, 반응형 FAB, 툴팁, Glasp 레이아웃
 ├── ai-fill.js           # Gemini / ChatGPT / Claude 입력창 자동 주입 스크립트
 ├── background.js        # 서비스 워커 (새 탭 생성, 탭 간 세션 핸드셰이크)
 ├── options.html         # 요약 프롬프트 커스텀 설정 웹페이지
 ├── options.js           # 프롬프트 동기화 및 chrome.storage.sync 관리
 └── README.md            # 전체 기능 및 사용 안내서
 ```
